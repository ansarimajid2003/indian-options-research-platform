# Options Backtest Reports

The top-level folder is reserved for the latest standard Dhan run.

Legacy and exploratory outputs live under `legacy/`:

- `legacy/runs/`: older timestamped strategy packs.
- `legacy/ad_hoc_dhan/`: pre-runner Dhan CSV outputs.
- `legacy/baselines/`: baseline intraday strategy reports.
- `legacy/smoke/`: small smoke-test ledgers.
- `legacy/perf_smoke/`: performance smoke reports.
- `legacy/bugfix/`: bugfix validation outputs.
- `legacy/research/`: one-off research slices and exploratory reports.

Keep generated reports grouped by run stamp when archiving old standard runs.
